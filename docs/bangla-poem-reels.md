# Bangla poem cartoon reels

## Target format

- Duration: 28 seconds
- Aspect ratio: 9:16
- Canvas: 1080 × 1920
- Frame rate: 24 or 30 fps
- Language: Bengali narration
- Style: Hand-styled 3D cartoon
- Motion: Keyframed camera and character movement
- No generated AI motion or 3D generation in the reel

## Suggested timeline

| Time | Shot | Notes |
|---|---|---|
| 0–3 sec | Opening title | Gentle push-in |
| 3–8 sec | Character introduction | Establish the scene |
| 8–15 sec | Poem visual 1 | Reveal supporting picture |
| 15–21 sec | Poem visual 2 | Emotional movement |
| 21–26 sec | Final image | Slow pull-back |
| 26–28 sec | Ending card | Add title or channel credit |

## Narration setup

- Record Bengali narration in a clean 48 kHz WAV file.
- Keep a slightly shorter 26–27 second voice track so timing has room.
- Place timing notes against each sentence.
- Reserve 1 second for the opening and 1–2 seconds for the closing card.

## Blender setup

1. Set render resolution to 1080 × 1920.
2. Set frame rate to 30 fps.
3. Set 28 seconds to exactly 840 frames.
4. Add each image as a 2D plane or textured 3D set.
5. Animate only camera transforms and pose/keyframe properties.
6. Use a 3D perspective camera with subtle depth-of-field.
7. Render an MP4 preview before final grading.

## Reel safety

- Use only licensed or original poetry and artwork.
- Credit the poet when the poem is by a public or historic author.
- Verify commercial rights for all music and background assets.
- Keep Bengali captions readable and avoid covering faces or important art.
